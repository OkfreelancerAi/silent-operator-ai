# Silent Operator AI

Agentic business automation platform.

- Landing page with skilled agents showcase
- Agent Marketplace
- Live Agent Console (dashboard)
- API route ready for full LLM + tools

## Deploy

Push to `main` triggers production deploy on Vercel.

### Environment variables (optional for live LLM)

```
OPENAI_API_KEY=
# or
ANTHROPIC_API_KEY=
```

## Local

```bash
npm install
npm run dev
```

## Stack

- Next.js 16 (App Router)
- Tailwind CSS 4
- TypeScript
- Ready for Vercel AI SDK / Stripe / Clerk
